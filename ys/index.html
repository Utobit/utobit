제작 과정 — AI와 함께 하루 안에

이 콘솔은 면접 전날 저녁, 지원자가 AI 코딩 에이전트(Claude Code)에 요구사항을 말로 전달하고 결과를 검토·수정하는 방식으로 만들었습니다. 코드 작성·서버 배포·지오코딩·사이트 캡처는 AI가 수행하고, 지원자는 방향 결정과 내용 검증을 맡았습니다.

1. 데이터 정리엑셀 이력서·참여사업 62건을 구조화 → 읍·면·리 단위 지오코딩(OSM Nominatim) → 지도 데이터
2. 지도·목록Leaflet + OpenStreetMap/위성 레이어, 회사별 필터·검색, 클릭 시 위치 이동
3. AI 백엔드AWS Lightsail의 FastAPI 서버에 Claude Opus 5 연동(스트리밍, Gemini 폴백) — 환경영향평가 특화 시스템 프롬프트, 평가대상 판단 모드, 요청 한도
4. 배포Netlify 정적 호스팅(utobit.net), 검색 비노출 설정, 연계기관 사이트 자동 캡처

같은 방식으로 실무에서는 현황조사표 자동 집계, 도면 일괄 편집, 보고서 초안 생성, 협의의견 DB 검색 같은 반복 작업을 도구화할 수 있습니다.
